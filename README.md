## What Is This?

This repository contains the deployment files for the **WPSecure Signature Inserter Outlook Web Add-in** — an Azure-hosted solution that silently inserts centrally managed email signatures into New Outlook and Outlook on the Web for every user in your organisation.

Signatures are fetched from each user's own OneDrive, processed by your own Azure Web App, and inserted directly into Outlook. Nothing leaves your Microsoft 365 tenant.
